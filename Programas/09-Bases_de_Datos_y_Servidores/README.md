# Categoría: 09-Bases de Datos y Servidores

Esta carpeta contiene los instaladores optimizados para Termux y Termux:X11 de esta categoría.

| Programa | Instalador | Descripción |
| :--- | :--- | :--- |
| **PostgreSQL Database Server** | [`instalar-postgresql.sh`](./instalar-postgresql.sh) | Sistema de base de datos relacional avanzada de nivel empresarial. |
| **MariaDB (MySQL) Server** | [`instalar-mariadb.sh`](./instalar-mariadb.sh) | Servidor de base de datos relacional optimizado para entornos móviles. |
| **Redis In-Memory Store** | [`instalar-redis.sh`](./instalar-redis.sh) | Almacén en memoria de clave-valor de alta velocidad para caché y colas. |
| **SQLite Engine** | [`instalar-sqlite.sh`](./instalar-sqlite.sh) | Motor de base de datos relacional ligera embebida sin servidor. |
| **MongoDB NoSQL Engine** | [`instalar-mongodb.sh`](./instalar-mongodb.sh) | Base de datos basada en documentos para aplicaciones modernas. |
| **DBeaver Universal Database Manager** | [`instalar-dbeaver.sh`](./instalar-dbeaver.sh) | Administrador visual universal de bases de datos relacionales y NoSQL. |
| **DB Browser for SQLite** | [`instalar-sqlitebrowser.sh`](./instalar-sqlitebrowser.sh) | Interfaz gráfica para crear, diseñar y editar bases de datos SQLite en X11. |
| **Nginx Web Server** | [`instalar-nginx.sh`](./instalar-nginx.sh) | Servidor web ligero y proxy inverso de alto rendimiento para proyectos. |
| **Caddy Web Server** | [`instalar-caddy.sh`](./instalar-caddy.sh) | Servidor web moderno en Go con configuración automática de puertos y rutas. |
| **Udocker Container Engine** | [`instalar-udocker.sh`](./instalar-udocker.sh) | Ejecución de contenedores tipo Docker en Android sin permisos de root. |
