# 📦 Catálogo Maestro de Software para Termux & Termux:X11 (+110 Programas)

Este directorio contiene **más de 110 instaladores automatizados** organizados por subcategorías, identificados con sus **nombres reales oficiales** y las **descripciones y taglines oficiales** de sus creadores.

## 🚀 ¿Cómo usar el Centro de Instalación?

1. **Modo Menú Interactivo (Recomendado)**: Ejecuta `programas` en cualquier terminal o corre `./menu-instalador.sh`.
2. **Desde el Escritorio X11**: Clic derecho en el fondo de pantalla -> `📦 Centro de Programas (+100 Apps)`.
3. **Modo Directo**: Ejecuta cualquier script directamente (ej: `bash 01-Editores_e_IA/instalar-cursor.sh`).
