# 📦 Catálogo Maestro de Programas e Instaladores para Termux & Termux:X11

Este directorio contiene **más de 100 instaladores automatizados** organizados por subcategorías para desplegar entornos de IA, navegadores, herramientas de diseño, suites de desarrollo, bases de datos y ciberseguridad en Android.

## 🚀 ¿Cómo usar los instaladores?

Puedes ejecutar cualquier instalador de tres formas:
1. **Modo Menú Interactivo (Recomendado)**: Ejecuta `./menu-instalador.sh` dentro de esta carpeta para elegir cualquier programa con flechas.
2. **Modo Directo**: Navega a cualquier subcarpeta y corre el script deseado (ej: `bash 01-Editores_e_IA/instalar-cursor.sh`).
