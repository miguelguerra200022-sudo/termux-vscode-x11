# 📦 Centro de Instalación de Programas para Termux & X11

Repositorio centralizado con **110 instaladores automatizados** organizados en 11 categorías especializadas para Termux con soporte gráfico Termux:X11.

## 🚀 Inicio Rápido
Puedes acceder al catálogo interactivo en cualquier momento ejecutando:
```bash
programas
```
O bien navegando y ejecutando el script del menú directamente:
```bash
bash ~/termux-vscode-x11/Programas/menu-instalador.sh
```

## 🛡️ Estándar de Empaquetado y Ejecución
- Todos los instaladores configuran repositorios oficiales (`tur-repo`, `x11-repo`, `root-repo`), instalan dependencias nativas o glibc según corresponda.
- Crean accesos directos en `$PREFIX/bin` para lanzamiento inmediato por terminal.
