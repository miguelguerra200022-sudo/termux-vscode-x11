# Terminales Modernas y Monitores de Recursos

Esta categoría contiene instaladores automatizados optimizados para **Termux y Termux:X11**.

## Programas Disponibles

| Script de Instalación | Nombre Oficial | Presentación Oficial de los Creadores |
|---|---|---|
| `instalar-alacritty.sh` | **Alacritty** | Emulador de terminal multiplataforma acelerado por GPU enfocado en rendimiento y simplicidad |
| `instalar-btop.sh` | **Btop++** | Monitor de recursos del sistema moderno con interfaz estética y soporte para ratón |
| `instalar-fastfetch.sh` | **Fastfetch** | Herramienta rápida y personalizable para mostrar información del sistema al instante |
| `instalar-htop.sh` | **Htop** | Visor y administrador interactivo de procesos para sistemas Unix en tiempo real |
| `instalar-kitty.sh` | **Kitty** | Emulador de terminal rápido y rico en funciones acelerado por GPU con soporte para gráficos |
| `instalar-lazydocker.sh` | **LazyDocker** | La interfaz de usuario en terminal más sencilla para gestionar contenedores Docker |
| `instalar-lazygit.sh` | **LazyGit** | Interfaz de usuario en terminal simple y rápida para gestionar flujos de trabajo de Git |
| `instalar-ranger.sh` | **Ranger** | Administrador de archivos para consola con atajos de teclado tipo VI y vista previa integrada |
| `instalar-tmux.sh` | **Tmux** | Multiplexor de terminales para gestionar múltiples sesiones, ventanas y paneles simultáneos |
| `instalar-xfce4-terminal.sh` | **XFCE4 Terminal** | Emulador de terminal ligero, altamente personalizable y eficiente para entornos X11 |
| `instalar-yazi.sh` | **Yazi** | Administrador de archivos de terminal asíncrono y ultrarrápido escrito en Rust con vista previa de imágenes |
| `instalar-zellij.sh` | **Zellij** | Espacio de trabajo y multiplexor de terminal intuitivo para desarrolladores con soporte de plugins |

## Uso
Para instalar cualquiera de estos programas, ejecuta el script correspondiente o abre el menú principal:
```bash
programas
```
