# Categoría: 07-Terminales y Monitores

Esta carpeta contiene los instaladores optimizados para Termux y Termux:X11 de esta categoría.

| Programa | Instalador | Descripción |
| :--- | :--- | :--- |
| **Alacritty GPU Terminal** | [`instalar-alacritty.sh`](./instalar-alacritty.sh) | Emulador de terminal ultra-rápido acelerado por GPU escrito en Rust. |
| **Kitty Terminal** | [`instalar-kitty.sh`](./instalar-kitty.sh) | Terminal moderna con soporte nativo de imágenes, fuentes y pestañas. |
| **XFCE4 Terminal** | [`instalar-xfce4-terminal.sh`](./instalar-xfce4-terminal.sh) | Terminal gráfica con pestañas, colores personalizables y menú contextual. |
| **Tmux Multiplexer** | [`instalar-tmux.sh`](./instalar-tmux.sh) | Multiplexor de terminales para mantener sesiones persistentes en background. |
| **Zellij Terminal Workspace** | [`instalar-zellij.sh`](./instalar-zellij.sh) | Multiplexor moderno en Rust con interfaz visual interactiva y plugins. |
| **Btop Resource Monitor** | [`instalar-btop.sh`](./instalar-btop.sh) | Monitor interactivo de CPU, memoria, discos y procesos con gráficos. |
| **Htop Process Viewer** | [`instalar-htop.sh`](./instalar-htop.sh) | Visor interactivo clásico de procesos y árbol de tareas del sistema. |
| **Fastfetch System Info** | [`instalar-fastfetch.sh`](./instalar-fastfetch.sh) | Herramienta de información de hardware y sistema ultra-rápida en C. |
| **Ranger File Manager** | [`instalar-ranger.sh`](./instalar-ranger.sh) | Administrador de archivos de consola con atajos Vim y previsualización. |
| **Yazi Async File Manager** | [`instalar-yazi.sh`](./instalar-yazi.sh) | Administrador de archivos en terminal escrito en Rust, asíncrono y visual. |
| **Lazygit Git TUI** | [`instalar-lazygit.sh`](./instalar-lazygit.sh) | Interfaz gráfica interactiva para terminal para operaciones de Git instantáneas. |
| **Lazydocker Container TUI** | [`instalar-lazydocker.sh`](./instalar-lazydocker.sh) | Interfaz de consola interactiva para administrar contenedores y volúmenes. |
