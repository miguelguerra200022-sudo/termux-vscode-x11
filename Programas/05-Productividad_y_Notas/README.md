# Ofimática, Gestión de Notas y Productividad

Esta categoría contiene instaladores automatizados optimizados para **Termux y Termux:X11**.

## Programas Disponibles

| Script de Instalación | Nombre Oficial | Presentación Oficial de los Creadores |
|---|---|---|
| `instalar-cherrytree.sh` | **CherryTree** | Aplicación jerárquica para toma de notas con resaltado de sintaxis y almacenamiento seguro |
| `instalar-drawio.sh` | **Diagrams.net (Draw.io)** | Software de diagramación y mapas conceptuales de nivel empresarial, libre y seguro |
| `instalar-evince.sh` | **Evince** | Visor de documentos ligero y versátil para múltiples formatos como PDF, PostScript y DjVu |
| `instalar-foliate.sh` | **Foliate** | Lector de libros electrónicos elegante, moderno y libre para el escritorio de Linux |
| `instalar-libreoffice.sh` | **LibreOffice** | La suite ofimática de productividad personal libre y de código abierto más potente |
| `instalar-logseq.sh` | **Logseq** | Plataforma de gestión del conocimiento basada en privacidad y enlaces bidireccionales |
| `instalar-marktext.sh` | **MarkText** | Editor Markdown simple, fluido y de código abierto centrado en velocidad y usabilidad |
| `instalar-obsidian.sh` | **Obsidian** | La base de conocimiento privada y flexible que se adapta a tu manera de pensar |
| `instalar-xournalpp.sh` | **Xournal++** | Software de toma de notas a mano y anotación de PDFs con soporte para tabletas gráficas |
| `instalar-zettlr.sh` | **Zettlr** | Editor Markdown para investigadores, periodistas y escritores académicos |

## Uso
Para instalar cualquiera de estos programas, ejecuta el script correspondiente o abre el menú principal:
```bash
programas
```
