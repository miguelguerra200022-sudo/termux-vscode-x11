# Diseño Gráfico, Modelado 3D y Multimedia

Esta categoría contiene instaladores automatizados optimizados para **Termux y Termux:X11**.

## Programas Disponibles

| Script de Instalación | Nombre Oficial | Presentación Oficial de los Creadores |
|---|---|---|
| `instalar-audacity.sh` | **Audacity** | El software de audio de código abierto más popular del mundo para grabar y editar |
| `instalar-blender.sh` | **Blender** | La suite de creación 3D de código abierto libre para modelado, animación y renderizado |
| `instalar-freecad.sh` | **FreeCAD** | Modelador 3D paramétrico de código abierto para diseño mecánico e ingeniería |
| `instalar-gimp.sh` | **GIMP** | El editor de imágenes GNU de código abierto y manipulación fotográfica profesional |
| `instalar-inkscape.sh` | **Inkscape** | Editor de gráficos vectoriales profesional y de código abierto para ilustración y diseño |
| `instalar-kdenlive.sh` | **Kdenlive** | Potente editor de video no lineal libre y de código abierto basado en MLT Framework |
| `instalar-krita.sh` | **Krita** | Programa profesional de pintura digital e ilustración libre para artistas |
| `instalar-librecad.sh` | **LibreCAD** | Aplicación de diseño asistido por computadora (CAD) 2D madura y de código abierto |
| `instalar-mpv.sh` | **MPV** | Reproductor multimedia de línea de comandos potente, rápido y con aceleración por hardware |
| `instalar-vlc.sh` | **VLC media player** | El reproductor multimedia multiplataforma libre y de código abierto que reproduce todo |

## Uso
Para instalar cualquiera de estos programas, ejecuta el script correspondiente o abre el menú principal:
```bash
programas
```
