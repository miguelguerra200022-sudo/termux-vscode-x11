# Categoría: 04-Diseno y Multimedia

Esta carpeta contiene los instaladores optimizados para Termux y Termux:X11 de esta categoría.

| Programa | Instalador | Descripción |
| :--- | :--- | :--- |
| **Blender 3D** | [`instalar-blender.sh`](./instalar-blender.sh) | Suite completa de modelado, esculpido, animación y renderizado 3D. |
| **GIMP (GNU Image Manipulation Program)** | [`instalar-gimp.sh`](./instalar-gimp.sh) | Editor avanzado de imágenes, retoque fotográfico y pintura digital. |
| **Inkscape Vector Graphics** | [`instalar-inkscape.sh`](./instalar-inkscape.sh) | Editor profesional de gráficos vectoriales SVG y diseño ilustrativo. |
| **Krita Digital Painting** | [`instalar-krita.sh`](./instalar-krita.sh) | Software profesional de pintura digital, ilustración conceptual y cómics. |
| **FreeCAD 3D** | [`instalar-freecad.sh`](./instalar-freecad.sh) | Modelador 3D paramétrico para diseño mecánico, CAD e ingeniería. |
| **LibreCAD 2D** | [`instalar-librecad.sh`](./instalar-librecad.sh) | Sistema CAD 2D ligero para diseño técnico y planos arquitectónicos. |
| **Audacity Audio Editor** | [`instalar-audacity.sh`](./instalar-audacity.sh) | Grabador y editor de audio multi-pista profesional con PulseAudio. |
| **VLC Media Player** | [`instalar-vlc.sh`](./instalar-vlc.sh) | Reproductor multimedia universal acelerado con soporte de audio. |
| **MPV Media Player** | [`instalar-mpv.sh`](./instalar-mpv.sh) | Reproductor ultra-ligero de audio y video con scripts Lua y bajo consumo. |
| **Kdenlive Video Editor** | [`instalar-kdenlive.sh`](./instalar-kdenlive.sh) | Editor de video no lineal profesional de código abierto. |
