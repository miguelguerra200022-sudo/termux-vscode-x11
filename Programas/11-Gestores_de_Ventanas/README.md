# Gestores de Ventanas y Escritorios Ligeros

Esta categoría contiene instaladores automatizados optimizados para **Termux y Termux:X11**.

## Programas Disponibles

| Script de Instalación | Nombre Oficial | Presentación Oficial de los Creadores |
|---|---|---|
| `instalar-awesomewm.sh` | **AwesomeWM** | Gestor de ventanas dinámico altamente configurable para X11 mediante scripts en Lua |
| `instalar-bspwm.sh` | **Bspwm** | Gestor de ventanas en mosaico que organiza las pantallas mediante árboles binarios particionados |
| `instalar-fluxbox.sh` | **Fluxbox** | Gestor de ventanas ligero y extremadamente rápido para X11 con soporte para pestañas |
| `instalar-i3-wm.sh` | **i3 Window Manager** | Gestor de ventanas en mosaico dinámico, eficiente y altamente configurable para Linux |
| `instalar-openbox.sh` | **Openbox** | Gestor de ventanas altamente configurable, rápido y con soporte total de estándares para X11 |
| `instalar-xfce4.sh` | **XFCE4 Desktop** | Entorno de escritorio tradicional, ligero, modular y rápido para sistemas tipo Unix |

## Uso
Para instalar cualquiera de estos programas, ejecuta el script correspondiente o abre el menú principal:
```bash
programas
```
